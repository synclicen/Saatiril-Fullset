📱 Langkah-langkah untuk Android:
  1. Pastikan USB OTG aktif — Buka Pengaturan → Setelan tambahan → OTG → Aktifkan
  2. Hubungkan USB capture card via kabel OTG ke HP
  3. Periksa notifikasi USB — Saat colok USB, akan muncul notifikasi. Tap notifikasi tersebut
  4. Izinkan akses kamera Chrome — Pengaturan → Aplikasi → Chrome → Izin → Kamera → Izinkan
  5. Aktifkan Chrome Flag (penting untuk HTTP):
    Buka tab baru → ketik chrome://flags
    Cari insecure origin
    Pada "Insecure origins treated as secure", masukkan:
    http://192.168.x.x:3000
    Pilih Enabled → Tap Relaunch
  6. Tutup dan buka ulang Chrome setelah colok USB
  7. Tap tombol "Izinkan Akses Kamera" di atas, lalu pilih izinkan
💡 Tips:
Jika tetap tidak terdeteksi, coba:
• Buka aplikasi Kamera bawaan HP → cek apakah USB capture card muncul
• Jika muncul di Kamera HP tapi tidak di Chrome, berarti Chrome perlu Chrome Flag
• Coba cabut dan pasang ulang USB capture card
• Pastikan HDMI cable terhubung ke kamera dan capture card
