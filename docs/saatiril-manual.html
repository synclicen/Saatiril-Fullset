Bab 01
Pendahuluan
Apa itu SAATIRIL?
SAATIRIL (Sistem Auto Track Input, Raw Into Live) adalah aplikasi desktop berbasis LAN yang dirancang khusus untuk mengelola proses foto wisuda secara real-time. Aplikasi ini menghubungkan Admin, Master of Ceremony (MC), dan Operator Kamera dalam satu jaringan lokal yang terkoordinasi.
Sistem ini bekerja sepenuhnya offline tanpa memerlukan koneksi internet. Komunikasi antar perangkat dilakukan melalui jaringan LAN menggunakan Socket.io, sehingga keamanan data terjaga dan tidak bergantung pada kualitas internet.
Tiga Peran Utama
◆ Admin
Menjalankan aplikasi Electron di laptop/PC utama. Bertanggung jawab membuat proyek, mengatur konfigurasi, menyimpan foto ke disk, dan mengontrol keseluruhan sesi. Admin adalah pusat koordinasi seluruh sistem.
◆ MC (Master of Ceremony)
Mengakses panel MC melalui browser (Chrome/Edge) di perangkat terpisah atau tab browser di laptop yang sama dengan Admin. Bertugas memanggil nama wisudawan dan mengatur ritme acara dari layar yang terhubung real-time.
◆ Operator Kamera
Mengakses panel Operator melalui browser di perangkat yang terhubung kamera. Bertugas mengambil foto wisudawan, melakukan retake jika diperlukan, dan mengirimkan foto ke Admin untuk disimpan. Mode kamera bisa single atau dual (2 jalur).
Fitur Utama
SAATIRIL menyediakan fitur-fitur berikut untuk mendukung kelancaran acara wisuda:
  • ✓ Sistem lisensi bulanan (30 hari) yang terikat ke hardware perangkat
  • ✓ Session password untuk keamanan jaringan LAN
  • ✓ Sinkronisasi data real-time antar semua perangkat via LAN
  • ✓ Mode kamera single, dual, single-photoshoot, dan dual-photoshoot
  • ✓ Filter preset foto (portrait ratio 9:16)
  • ✓ Auto-save foto ke disk oleh Admin (format: NIM_Nama.jpg)
  • ✓ Retake foto dengan versi otomatis (v2, v3, dst.)
  • ✓ Monitor kualitas koneksi LAN secara real-time
  • ✓ Admin dan MC bisa berjalan di laptop yang sama
Bab 02
Persiapan Hardware & Software
Kebutuhan Admin
◆ Perangkat Admin
Hardware: Laptop/PC dengan Windows 10/11, RAM minimal 8 GB (disarankan 16 GB untuk dual mode), penyimpanan kosong minimal 10 GB untuk foto, dan koneksi LAN/WiFi ke router.

Software: Aplikasi SAATIRIL (versi Installer atau Portable), Google Chrome atau Microsoft Edge (jika MC berjalan di laptop yang sama).

Aksesoris: Kabel LAN (opsional, untuk koneksi stabil) atau koneksi WiFi ke router yang sama.
Kebutuhan MC
◆ Perangkat MC
Hardware: Laptop, tablet, atau perangkat apapun dengan browser modern. Bisa menggunakan perangkat yang sama dengan Admin (tab browser terpisah).

Software: Google Chrome atau Microsoft Edge (versi terbaru). Tidak perlu instalasi tambahan.

Koneksi: Harus terhubung ke jaringan LAN/WiFi yang sama dengan Admin.
Kebutuhan Operator
◆ Perangkat Operator
Hardware: Laptop/PC dengan kamera webcam atau kamera USB yang terhubung. Untuk mode dual, dibutuhkan 2 perangkat Operator masing-masing dengan kamera.

Software: Google Chrome atau Microsoft Edge (versi terbaru). Tidak perlu instalasi tambahan.

Koneksi: Harus terhubung ke jaringan LAN/WiFi yang sama dengan Admin.
Kebutuhan Jaringan
Router/Switch LAN
Router WiFi: Semua perangkat harus terhubung ke router yang sama, baik via kabel LAN maupun WiFi. Router tidak perlu terhubung ke internet.

Switch LAN (opsional): Untuk koneksi yang lebih stabil, gunakan switch LAN dan kabel Ethernet ke setiap perangkat.

Kapasitas: Maksimal 10 perangkat terhubung sekaligus (batas sistem). Disarankan 3-4 perangkat untuk performa optimal.
Penting: Jaringan Tidak Perlu Internet
SAATIRIL berjalan sepenuhnya offline di jaringan lokal. Router hanya digunakan sebagai penghubung antar perangkat. Jika router juga terhubung ke internet, itu tidak akan mengganggu operasional SAATIRIL. Yang penting semua perangkat berada di jaringan lokal yang sama.
Bab 03
Sistem Lisensi & Aktivasi
SAATIRIL dilindungi oleh sistem lisensi offline. Setiap instalasi harus diaktivasi dengan kode unik yang terikat ke hardware perangkat. Lisensi berlaku selama 30 hari (1 bulan) sejak tanggal pembuatan kode. Setelah habis masa aktif, aplikasi akan terkunci dan harus meminta kode baru dari pengembang.
Tanpa Kode = Tidak Bisa Digunakan
Aplikasi SAATIRIL tidak memiliki masa percobaan (grace period). Jika tidak memiliki kode aktivasi yang valid, aplikasi akan langsung terkunci dan tidak dapat digunakan sama sekali.

Langkah Detail: Aktivasi Pertama Kali
  1. 1
    Buka Aplikasi SAATIRIL
    Klik dua kali ikon SAATIRIL di desktop atau jalankan file SAATIRIL-Portable.exe. Akan muncul layar aktivasi bertuliskan "Aplikasi Terkunci".
  2. 2
    Salin Machine ID
    Di layar aktivasi, terdapat kotak "ID Perangkat (Machine ID)" yang menampilkan kode seperti A1B2-C3D4-E5F6. Klik tombol "Salin" di sebelahnya untuk menyalin ID lengkap (64 karakter) ke clipboard.
  3. 3
    Kirim Machine ID ke Pengembang
    Kirimkan Machine ID tersebut ke pengembang SAATIRIL melalui WhatsApp, email, atau media komunikasi lainnya. Pastikan mengirim ID lengkap, bukan versi singkat.
  4. 4
    Terima Kode Aktivasi
    Pengembang akan memproses Machine ID Anda dan mengirimkan balik kode aktivasi dalam format XXXX-XXXX-XXXX-XXXX. Kode ini unik untuk perangkat Anda dan tidak bisa digunakan di komputer lain.
  5. 5
    Masukkan Kode Aktivasi
    Ketik kode aktivasi di kolom input. Kode akan otomatis terformat dengan tanda hubung saat Anda mengetik. Setelah selesai, klik tombol "Aktivasi" atau tekan Enter.
  6. 6
    Aplikasi Terbuka
    Jika kode valid, muncul pesan "Lisensi Diaktifkan!" dan aplikasi akan memuat otomatis. Lisensi berlaku selama 30 hari sejak tanggal kode dibuat oleh pengembang.
Masa Berlaku Lisensi
Setiap kode aktivasi berlaku selama 30 hari sejak tanggal pembuatan. Saat masa aktif tersisa 7 hari atau kurang, akan muncul peringatan kuning di layar untuk mengingatkan Anda segera menghubungi pengembang untuk mendapatkan kode baru. Setelah expired, aplikasi akan terkunci dan harus diaktivasi ulang dengan kode baru.
Prosedur Perpanjangan Lisensi
Ketika lisensi sudah expired atau akan expired, lakukan langkah yang sama dengan aktivasi pertama: salin Machine ID, kirim ke pengembang, terima kode baru, masukkan kode. Machine ID tidak berubah selama perangkat hardware sama, jadi pengembang bisa generate kode baru dengan cepat.
Tips: Jangan Tunggu Expired!
Minta kode baru setidaknya 2-3 hari sebelum lisensi expired. Dengan demikian, Anda bisa langsung memasukkan kode baru tanpa gangguan operasional. Kode baru akan menimpa lisensi lama dan memperpanjang masa aktif 30 hari dari tanggal kode baru dibuat.
Bab 04
Setup Jaringan LAN
Topologi Jaringan
Semua perangkat harus terhubung ke satu router yang sama. Baik menggunakan kabel LAN maupun WiFi, yang penting berada dalam jaringan lokal (subnet) yang identik. Router tidak perlu terhubung ke internet.
Contoh Topologi
                 [ Router / Switch ]
                    |    |    |
    [ Laptop Admin ]  [ Laptop MC ]  [ Laptop Operator ]
    (SAATIRIL app)   (Chrome/Edge)  (Chrome/Edge + Kamera)
    IP: 192.168.1.10  IP: 192.168.1.11  IP: 192.168.1.12
Langkah Setup Jaringan
  1. 1
    Nyalakan Router
    Hidupkan router WiFi atau switch LAN. Pastikan DHCP server aktif agar setiap perangkat mendapat IP address otomatis.
  2. 2
    Hubungkan Semua Perangkat
    Sambungkan setiap laptop/PC ke router, baik via kabel LAN maupun WiFi. Pastikan semuanya mendapat IP address dari range yang sama (misalnya 192.168.1.x).
  3. 3
    Verifikasi Koneksi
    Dari laptop Admin, buka Command Prompt dan ping ke IP perangkat lain (contoh: ping 192.168.1.11). Jika ada balasan, jaringan sudah siap.
WiFi dan Kabel LAN Bisa Dicampur
Perangkat yang terhubung via WiFi dan kabel LAN ke router yang sama tetap bisa saling berkomunikasi karena berada di subnet yang sama. Namun, untuk stabilitas terbaik, disarankan Admin menggunakan kabel LAN karena bertanggung jawab menyimpan foto.

Bab 05
Panduan Admin
Admin adalah peran utama yang menjalankan aplikasi SAATIRIL di Electron. Berikut panduan lengkap dari persiapan hingga operasional.
Langkah 1: Aktivasi Lisensi
Saat pertama kali membuka SAATIRIL, akan muncul layar aktivasi. Ikuti prosedur aktivasi lisensi yang dijelaskan di Bab 3. Setelah berhasil, Anda akan masuk ke halaman utama.
Langkah 2: Buat Proyek Baru
  1. 1
    Klik "Buat Proyek Baru"
    Di halaman Project Hub, klik tombol buat proyek baru untuk memulai konfigurasi.
  2. 2
    Isi Informasi Proyek
    Masukkan nama acara (contoh: "Wisuda UIN Antasari 2026"), tahun, dan detail lainnya.
  3. 3
    Pilih Mode Kamera
    Pilih salah satu: Single (1 kamera, 1 jalur), Dual (2 kamera, 2 jalur), Single Photoshoot, atau Dual Photoshoot. Mode dual membutuhkan 2 operator kamera.
  4. 4
    Pilih Folder Penyimpanan Foto
    Klik "Pilih Folder" dan tentukan lokasi penyimpanan foto di disk. Semua foto yang diambil operator akan otomatis tersimpan di folder ini dengan format nama: NIM_Nama.jpg
  5. 5
    Set Session Password
    Buat password untuk sesi LAN. Password ini harus dimasukkan oleh MC dan Operator sebelum bisa bergabung. Catat password ini dan sampaikan kepada petugas terkait secara aman (via WhatsApp pribadi atau lisan).
  6. 6
    Simpan dan Mulai
    Klik simpan untuk membuat proyek. Server Socket.io akan otomatis berjalan di port 3003 dan siap menerima koneksi dari perangkat lain.
Langkah 3: Bagikan Informasi Kepada Petugas
Setelah proyek dibuat, Admin perlu membagikan informasi berikut kepada MC dan Operator agar mereka bisa bergabung:
Informasi yang Dibagikan
1. IP Address Admin — Tampil di header aplikasi SAATIRIL (contoh: 192.168.1.10).
2. Session Password — Password yang sudah dibuat saat setup proyek.
3. Port — Default 3003 (sudah otomatis, tidak perlu disebutkan kecuali ada perubahan).

Kirimkan informasi ini melalui WhatsApp atau sampaikan secara lisan. Pastikan hanya petugas yang berwenang yang mengetahui password.
Langkah 4: Operasional Saat Acara
Selama acara berlangsung, Admin mengawasi dashboard yang menampilkan status koneksi setiap perangkat, foto yang masuk secara real-time, dan daftar wisudawan. Admin bisa berpindah tab antara Admin Dashboard, Panel MC, dan Panel Operator untuk monitoring. Foto yang diambil operator akan otomatis tersimpan ke folder yang sudah ditentukan tanpa perlu intervensi manual.
Tips: Admin + MC di Laptop yang Sama
Jika MC tidak memiliki perangkat terpisah, Admin bisa membuka panel MC di tab browser di laptop yang sama. Buka Chrome/Edge, lalu akses panel MC menggunakan URL yang tersedia di header aplikasi. Panel MC akan muncul di tab browser sementara Admin Dashboard tetap terbuka di aplikasi Electron.
Bab 06
Panduan MC
MC (Master of Ceremony) mengakses SAATIRIL melalui browser di perangkat terpisah atau di laptop yang sama dengan Admin. MC tidak perlu menginstal aplikasi apapun, cukup menggunakan browser.
Langkah 1: Buka Browser
Buka Google Chrome atau Microsoft Edge di perangkat MC. Pastikan perangkat sudah terhubung ke jaringan LAN yang sama dengan Admin.
Langkah 2: Akses Panel MC
Masukkan URL berikut di address bar browser:
http://[IP-ADMIN]:3000/?role=mc
Ganti [IP-ADMIN] dengan IP address laptop Admin yang diberikan oleh Admin. Contoh: http://192.168.1.10:3000/?role=mc
Jika MC di Laptop yang Sama dengan Admin
Jika MC berjalan di laptop yang sama dengan Admin, gunakan URL: http://localhost:3000/?role=mc atau klik link yang tersedia di header aplikasi SAATIRIL.
Langkah 3: Masukkan Session Password
Saat pertama kali terhubung, server akan meminta Session Password. Masukkan password yang sudah diberikan oleh Admin. Jika password salah, koneksi akan ditolak dan Anda harus mencoba lagi. Jika password benar, panel MC akan terbuka dan menampilkan daftar wisudawan secara real-time.
Langkah 4: Operasional MC
Di panel MC, Anda akan melihat daftar wisudawan yang bisa dipanggil satu per satu. Klik tombol "Panggil" untuk mengirim nama wisudawan ke layar Operator. Status setiap wisudawan (menunggu, dipanggil, selesai foto) akan terupdate secara real-time. Anda juga bisa melihat pratinjau foto yang baru diambil. Semua data tersinkronisasi otomatis dengan Admin dan Operator tanpa perlu refresh manual.
Jangan Tutup Tab Browser
Selama acara berlangsung, jangan menutup tab browser atau mematikan perangkat. Jika koneksi terputus, sistem akan otomatis mencoba menyambung kembali, tetapi data yang dikirim saat offline mungkin tertunda. Jika tab tertutup, buka kembali URL yang sama dan masukkan password lagi.
Bab 07
Panduan Operator Kamera
Operator Kamera mengakses SAATIRIL melalui browser di perangkat yang memiliki kamera. Operator bertugas mengambil foto wisudawan dan mengirimkannya ke Admin untuk disimpan.
Langkah 1: Siapkan Kamera
Pastikan kamera webcam atau kamera USB sudah terhubung ke laptop/PC dan dikenali oleh sistem. Di browser, Anda perlu memberikan izin akses kamera saat diminta. Jika menggunakan mode dual, pastikan setiap operator memiliki perangkat masing-masing.
Langkah 2: Akses Panel Operator
Buka Google Chrome atau Microsoft Edge, lalu masukkan URL berikut:
http://[IP-ADMIN]:3000/?role=operator&channel=1
Untuk mode dual, Operator kedua menggunakan channel=2:
http://[IP-ADMIN]:3000/?role=operator&channel=2
Langkah 3: Masukkan Session Password
Sama seperti MC, Operator harus memasukkan Session Password yang diberikan Admin. Setelah berhasil, panel Operator akan terbuka dan kamera akan aktif secara otomatis.
Langkah 4: Ambil Foto
  1. 1
    Tunggu Wisudawan
    Panel akan menampilkan informasi wisudawan yang sedang dipanggil oleh MC. Kamera akan menampilkan live preview.
  2. 2
    Posisikan Kamera
    Arahkan kamera ke wisudawan sesuai posisi yang ditentukan. Pastikan pencahayaan cukup dan framing sudah tepat.
  3. 3
    Klik Tombol Capture
    Klik tombol "Capture" untuk mengambil foto. Foto akan otomatis dikirim ke Admin untuk disimpan ke disk dengan format nama: NIM_Nama.jpg. Pratinjau foto akan muncul di panel.
  4. 4
    Retake (Jika Diperlukan)
    Jika foto kurang bagus, klik tombol "Retake" untuk mengambil ulang. Foto retake akan disimpan sebagai versi baru (NIM_Nama_v2.jpg, dst.) sehingga foto asli tidak hilang.
Tips: Pilih Filter Preset
Di panel Operator, tersedia pilihan filter preset foto yang bisa dipilih sebelum capture. Filter akan diterapkan langsung pada foto yang diambil. Pilih preset yang paling cocok dengan kondisi pencahayaan lokasi.
Bab 08
Alur Operasional Acara Wisuda
Berikut adalah alur lengkap dari persiapan hingga selesainya acara wisuda menggunakan SAATIRIL. Ikuti setiap tahap secara berururan untuk memastikan kelancaran acara.
Fase 1: Persiapan (H-1 s/d Hari-H Pagi)
  1. 1
    Setup Jaringan LAN Admin
    Nyalakan router, hubungkan semua perangkat, verifikasi koneksi antar perangkat dengan ping test.
  2. 2
    Aktivasi Lisensi Admin
    Buka SAATIRIL, pastikan lisensi masih aktif. Jika expired, segera hubungi pengembang untuk kode baru.
  3. 3
    Buat Proyek Admin
    Buat proyek baru, pilih mode kamera, tentukan folder penyimpanan, dan set session password.
  4. 4
    Bagikan Info Kepada Petugas Admin
    Sampaikan IP Address Admin dan Session Password kepada MC dan Operator. Gunakan kanal komunikasi yang aman.
  5. 5
    Persiapan Kamera Operator
    Hubungkan kamera ke laptop, buka browser, akses panel Operator, masukkan password, dan verifikasi kamera berfungsi dengan baik.
Fase 2: Uji Coba (30 Menit Sebelum Acara)
  1. 1
    Test Koneksi Semua Perangkat
    Pastikan MC dan Operator sudah terhubung. Periksa indikator koneksi di header masing-masing panel. Status harus menunjukkan "Connected" dengan kualitas "Good" atau "Excellent".
  2. 2
    Test Ambil Foto
    Minta operator untuk mengambil 1-2 foto percobaan. Verifikasi foto muncul di Admin Dashboard dan tersimpan di folder yang benar. Cek juga apakah retake berfungsi normal.
  3. 3
    Test Panel MC
    Minta MC untuk memanggil satu wisudawan percobaan. Pastikan nama muncul di panel Operator dan Admin.
Fase 3: Pelaksanaan Acara
  1. 1
    MC Memanggil Wisudawan MC
    MC memanggil nama wisudawan dari panel MC. Nama wisudawan akan muncul di layar Operator sebagai wisudawan yang sedang aktif.
  2. 2
    Operator Mengambil Foto Operator
    Operator memposisikan kamera dan mengklik "Capture". Foto otomatis terkirim ke Admin dan tersimpan ke disk. Retake jika perlu.
  3. 3
    Admin Monitoring Admin
    Admin mengawasi dashboard, memastikan foto tersimpan, dan memantau status koneksi semua perangkat. Jika ada masalah, segera koordinasi dengan petugas terkait.
  4. 4
    Ulangi untuk Wisudawan Berikutnya
    Siklus panggil-ambil foto-monitoring diulang untuk setiap wisudawan hingga seluruh wisudawan selesai diproses.
Fase 4: Selesai Acara
  1. 1
    Verifikasi Kelengkapan Foto Admin
    Periksa folder penyimpanan dan pastikan semua foto wisudawan sudah tersimpan. Cek apakah ada foto yang perlu di-retake.
  2. 2
    Tutup Aplikasi Admin
    Setelah semua foto terverifikasi, tutup aplikasi SAATIRIL. Server akan mengirim notifikasi ke semua perangkat yang terhubung sebelum dimatikan.
  3. 3
    Backup Foto Admin
    Salin folder foto ke media backup (flashdisk, harddisk eksternal, atau cloud storage) untuk keamanan data.
Bab 09
Troubleshooting
Masalah Lisensi
"Kode aktivasi tidak valid untuk perangkat ini"
Penyebab: Kode aktivasi yang dimasukkan tidak cocok dengan Machine ID perangkat ini. Kemungkinan kode dibuat untuk komputer lain, atau ada kesalahan saat menyalin Machine ID.

Solusi: Salin ulang Machine ID lengkap dari layar aktivasi (klik "Salin") dan kirimkan ke pengembang. Pastikan mengirim 64 karakter penuh, bukan versi singkat.
"Kode aktivasi sudah kadaluarsa"
Penyebab: Kode aktivasi yang dimasukkan sudah melewati masa berlaku 30 hari.

Solusi: Hubungi pengembang untuk mendapatkan kode aktivasi baru. Kode lama tidak bisa digunakan lagi. Prosesnya sama: kirim Machine ID, terima kode baru, masukkan kode.
Lisensi tiba-tiba tidak valid setelah perangkat diganti komponen
Penyebab: Machine ID dihitung dari hardware (CPU, MAC address, hostname). Jika komponen hardware berubah (ganti NIC, upgrade CPU), Machine ID akan berubah dan lisensi lama tidak lagi valid.

Solusi: Hubungi pengembang dengan Machine ID baru untuk mendapatkan kode aktivasi baru.
Masalah Koneksi
MC/Operator tidak bisa terhubung ke server
Langkah Pengecekan:
1. Pastikan perangkat terhubung ke jaringan yang sama (ping IP Admin)
2. Pastikan aplikasi SAATIRIL sudah berjalan di laptop Admin
3. Periksa apakah IP Address yang dimasukkan benar
4. Coba akses http://[IP-ADMIN]:3000 langsung di browser
5. Nonaktifkan firewall Windows sementara untuk testing
6. Pastikan tidak ada aplikasi lain yang menggunakan port 3000 atau 3003
"Session Password salah"
Penyebab: Password yang dimasukkan tidak cocok dengan yang diset oleh Admin.

Solusi: Verifikasi kembali password dengan Admin. Password bersifat case-sensitive (huruf besar/kecil berpengaruh). Jika lupa password, Admin bisa mengatur ulang dari aplikasi.
Koneksi sering terputus
Penyebab: Sinyal WiFi lemah atau interferensi.

Solusi: Gunakan kabel LAN untuk koneksi yang lebih stabil. Jika harus WiFi, pastikan perangkat dekat dengan router dan tidak ada hambatan fisik. Sistem akan otomatis mencoba menyambung kembali saat koneksi pulih.
Masalah Kamera
Kamera tidak terdeteksi di browser
Langkah Pengecekan:
1. Pastikan kamera terhubung dan dikenali oleh Windows (Device Manager)
2. Berikan izin akses kamera saat browser meminta (klik "Allow")
3. Jika kamera digunakan aplikasi lain, tutup aplikasi tersebut terlebih dahulu
4. Coba ganti kamera dari dropdown di panel Operator
5. Restart browser dan coba lagi
Foto tidak tersimpan di folder
Penyebab: Hanya Admin (Electron app) yang bisa menyimpan foto ke disk. Operator di browser tidak menyimpan langsung.

Solusi: Pastikan aplikasi SAATIRIL di laptop Admin berjalan dan terhubung. Foto yang diambil Operator akan dikirim ke Admin melalui jaringan LAN dan disimpan otomatis oleh Admin. Periksa koneksi antara Operator dan Admin.
Masalah Lainnya
Aplikasi SAATIRIL tidak mau terbuka (Windows)
Langkah Pengecekan:
1. Untuk versi Portable: klik kanan file .exe → "Run as Administrator"
2. Untuk versi Installer: jalankan dari shortcut Desktop atau Start Menu
3. Nonaktifkan antivirus sementara (Windows Defender kadang memblokir aplikasi baru)
4. Pastikan tidak ada instance SAATIRIL lain yang sedang berjalan (cek Task Manager)
Data sinkronisasi tidak muncul di perangkat lain
Penyebab: Koneksi terputus saat data dikirim, atau perangkat belum terautentikasi.

Solusi: Pastikan semua perangkat sudah memasukkan Session Password dengan benar. Periksa indikator koneksi di header. Jika koneksi pulih setelah terputus, data akan otomatis tersinkronisasi melalui mekanisme SYNC_DB.
