Bab 01
Pengantar
Apa itu SAATIRIL?
SAATIRIL (Sistem Auto Track Input, Raw Into Live) adalah aplikasi desktop berbasis LAN yang dirancang khusus untuk mengelola proses foto wisuda di UIN Antasari Banjarmasin secara real-time. Aplikasi ini menghubungkan Pengembang, Admin, Master of Ceremony (MC), dan Operator Kamera dalam satu jaringan lokal yang terkoordinasi, sehingga setiap tahapan dari pemanggilan wisudawan hingga penyimpanan foto dapat berjalan dengan lancar dan terdokumentasi.
Sistem ini bekerja sepenuhnya offline tanpa memerlukan koneksi internet. Komunikasi antar perangkat dilakukan melalui jaringan LAN menggunakan Socket.io pada port 3003, sehingga keamanan data terjaga dan tidak bergantung pada kualitas koneksi internet. Hal ini sangat penting mengingat acara wisuda membutuhkan keandalan tinggi dan tidak boleh terganggu oleh masalah konektivitas eksternal.
Aplikasi SAATIRIL dilengkapi dengan sistem lisensi bulanan yang terikat ke hardware perangkat Admin, sehingga setiap instalasi hanya dapat diaktifkan dengan kode aktivasi yang valid. Selain itu, keamanan sesi LAN dijaga melalui session password yang harus dimasukkan oleh setiap MC dan Operator sebelum dapat bergabung ke dalam sesi. Dengan kombinasi keamanan ini, data dan proses wisuda tetap terlindungi dari akses yang tidak berwenang.
Empat Peran Utama
◆ Pengembang (Developer)
Bertanggung jawab menghasilkan kode aktivasi lisensi menggunakan CLI tool yang tersedia di repositori proyek. Pengembang tidak perlu hadir di lokasi acara, namun harus siap dihubungi ketika Admin memerlukan kode aktivasi baru, baik saat pertama kali aktivasi maupun saat perpanjangan lisensi bulanan.
◆ Admin
Menjalankan aplikasi Electron di laptop/PC utama. Bertanggung jawab mengaktivasi lisensi, membuat proyek wisuda, mengatur session password untuk LAN, menyimpan foto ke disk, dan mengontrol keseluruhan sesi. Admin adalah pusat koordinasi seluruh sistem dan satu-satunya peran yang menjalankan aplikasi desktop.
◆ MC (Master of Ceremony)
Mengakses panel MC melalui browser di perangkat terpisah atau tab browser di laptop yang sama dengan Admin. Bertugas memanggil nama wisudawan dan mengatur ritme acara dari layar yang terhubung real-time ke sistem. MC memiliki dua channel yang dapat digunakan secara bersamaan untuk mendukung jalur wisuda paralel.
◆ Operator Kamera
Mengakses panel Operator melalui browser di perangkat yang terhubung kamera. Bertugas mengambil foto wisudawan, melakukan retake jika diperlukan, dan mengirimkan foto ke Admin untuk disimpan secara otomatis. Operator berkomunikasi secara real-time dengan Admin melalui jaringan LAN.
Persyaratan Sistem
Sebelum menggunakan SAATIRIL, pastikan perangkat dan lingkungan jaringan memenuhi persyaratan minimum berikut ini. Kegagalan memenuhi persyaratan dapat menyebabkan aplikasi tidak berjalan optimal atau gagal total.
  • ✓ Sistem operasi: Windows 10 atau 11 (64-bit)
  • ✓ RAM minimal 8 GB, disarankan 16 GB untuk mode dual kamera
  • ✓ Penyimpanan kosong minimal 10 GB untuk folder foto wisuda
  • ✓ Jaringan LAN atau WiFi yang stabil (router yang sama untuk semua perangkat)
  • ✓ Browser modern: Google Chrome atau Microsoft Edge (versi terbaru)
  • ✓ Kamera yang kompatibel dengan browser (USB webcam atau DSLR dengan software capture)
  • ✓ Port 3000 dan 3003 tidak digunakan oleh aplikasi lain
Bab 02
Persiapan Sebelum Acara
Persiapan yang matang sebelum hari acara adalah kunci keberhasilan operasional SAATIRIL. Setiap peran memiliki daftar tugas yang harus diselesaikan sebelum acara dimulai. Pastikan semua checklist berikut terpenuhi untuk menghindari masalah teknis di tengah berlangsungnya wisuda.
Checklist Pengembang
◆ Persiapan Pengembang
Pengembang harus memastikan bahwa tools untuk generate kode aktivasi sudah siap dan berfungsi. Periksa kembali bahwa repositori proyek sudah ter-update dan CLI tool generate-license.ts dapat dijalankan tanpa error. Siapkan juga daftar kontak Admin yang dapat menghubungi saat dibutuhkan kode aktivasi baru, terutama mendekati tanggal kadaluarsa lisensi.
  • ✓ Pastikan CLI tool generate-license.ts berjalan normal
  • ✓ Siapkan Node.js dan TypeScript runtime di komputer pengembang
  • ✓ Catat tanggal kadaluarsa lisensi yang sudah diterbitkan
  • ✓ Siapkan jalur komunikasi cepat dengan Admin (WhatsApp/Telegram)
Checklist Admin
◆ Persiapan Admin
Admin harus menyiapkan laptop utama, memastikan lisensi masih aktif atau meminta kode baru dari pengembang, menyiapkan jaringan LAN/WiFi, menginstal aplikasi SAATIRIL, dan memverifikasi bahwa semua perangkat MC dan Operator dapat terhubung ke jaringan yang sama. Jangan lupa menyiapkan kabel LAN sebagai cadangan jika WiFi bermasalah.
  • ✓ Instal atau jalankan aplikasi SAATIRIL di laptop utama
  • ✓ Verifikasi lisensi masih aktif (cek tanggal kadaluarsa di aplikasi)
  • ✓ Jika lisensi sudah kadaluarsa, kirim Machine ID ke pengembang untuk kode baru
  • ✓ Siapkan router WiFi dan/atau switch LAN
  • ✓ Catat IP Address laptop Admin (digunakan oleh MC dan Operator untuk koneksi)
  • ✓ Buat proyek wisuda baru di aplikasi
  • ✓ Set session password dan sampaikan ke MC dan Operator
  • ✓ Siapkan folder penyimpanan foto dengan ruang kosong cukup
Checklist MC
◆ Persiapan MC
MC memastikan perangkat browser sudah siap, terhubung ke jaringan yang sama dengan Admin, dan mengetahui IP Address Admin serta session password. Sebaiknya MC juga menyiapkan daftar nama wisudawan yang akan dipanggil agar acara berjalan lancar tanpa jeda.
  • ✓ Bawa laptop/tablet dengan browser modern (Chrome/Edge)
  • ✓ Dapatkan IP Address Admin dan session password
  • ✓ Pastikan terhubung ke jaringan LAN/WiFi yang sama
  • ✓ Siapkan daftar wisudawan sesuai channel yang ditugaskan
  • ✓ Uji akses ke URL panel MC sebelum acara dimulai
Checklist Operator
◆ Persiapan Operator
Operator harus memastikan kamera berfungsi baik, browser dapat mengakses kamera, dan perangkat terhubung ke jaringan LAN yang sama dengan Admin. Test ambil foto sebelum acara untuk memastikan seluruh rantai (kamera, browser, LAN, Admin) bekerja tanpa hambatan.
  • ✓ Siapkan laptop dengan kamera USB/DSLR terhubung
  • ✓ Pastikan browser mendeteksi kamera (cek izin akses kamera)
  • ✓ Dapatkan IP Address Admin dan session password
  • ✓ Pastikan terhubung ke jaringan LAN/WiFi yang sama
  • ✓ Uji ambil foto dan verifikasi foto muncul di Admin
Penting: Jaringan LAN yang Sama
Semua perangkat (Admin, MC, Operator) harus terhubung ke jaringan LAN atau WiFi yang sama. Jika Admin menggunakan kabel LAN dan MC menggunakan WiFi, pastikan keduanya berada di subnet yang sama (biasanya 192.168.x.x). Jika tidak, perangkat tidak akan dapat saling berkomunikasi.
Bab 03
Alur Kerja Pengembang
Pengembang (Developer) memiliki peran krusial dalam menjaga kelangsungan operasional SAATIRIL melalui penerbitan kode aktivasi lisensi. Tanpa kode aktivasi yang valid, aplikasi akan terkunci dan tidak dapat digunakan. Oleh karena itu, pengembang harus responsif terhadap permintaan kode dari Admin, terutama menjelang dan saat acara wisuda berlangsung.
Mendapatkan Machine ID dari Admin
Ketika Admin membuka aplikasi SAATIRIL untuk pertama kali atau setelah lisensi kadaluarsa, layar LicenseGate akan muncul dengan menampilkan Machine ID perangkat. Machine ID adalah sidik jari hardware unik sepanjang 64 karakter heksadesimal yang dihitung dari kombinasi CPU, MAC address, dan hostname perangkat Admin. Tidak ada dua komputer yang memiliki Machine ID yang sama.
Admin dapat menyalin Machine ID tersebut dengan mengklik tombol "Salin" yang tersedia di layar aktivasi. Machine ID inilah yang harus dikirimkan kepada pengembang agar kode aktivasi yang dihasilkan benar-benar cocok untuk perangkat tersebut. Pastikan Admin mengirimkan 64 karakter lengkap, bukan versi yang terpotong.
Format Machine ID
Machine ID terdiri dari 64 karakter heksadesimal (0-9, a-f). Contoh tampilan di layar Admin:
a3f8b2c1d4e5f607890abcdef1234567890abcdef1234567890abcdef12345678

Machine ID dihitung menggunakan SHA-256 dari gabungan CPU identifier + MAC address + hostname perangkat.
Menjalankan CLI Tool untuk Generate Kode Aktivasi
Setelah menerima Machine ID dari Admin, pengembang menjalankan CLI tool yang tersedia di repositori proyek untuk menghasilkan kode aktivasi. Tool ini menggunakan secret key khusus yang hanya diketahui oleh pengembang untuk memastikan keaslian setiap kode yang diterbitkan.
  1. 1
    Buka Terminal di Direktori Proyek
    Navigasikan ke direktori root proyek SAATIRIL di komputer pengembang. Pastikan Node.js dan dependensi proyek sudah terinstal dengan menjalankan npm install jika belum.
  2. 2
    Jalankan Perintah Generate License
    Eksekusi perintah berikut dengan mengganti <machineId> dengan Machine ID yang diterima dari Admin:
npx tsx tools/generate-license.ts <machineId>
  1. 3
    Baca Output dan Kirim ke Admin
    CLI tool akan menampilkan kode aktivasi dalam format XXXX-XXXX-XXXX-XXXX beserta tanggal kadaluarsa. Salin kode tersebut dan kirimkan ke Admin melalui jalur komunikasi yang aman.
Contoh Output CLI Tool
$ npx tsx tools/generate-license.ts a3f8b2c1d4e5...

Machine ID : a3f8b2c1d4e5f607...
Code : A1B2-C3D4-E5F6-7890
Expires : 2026-04-15
Days Left : 30
Dari output di atas, kode aktivasi yang harus dikirimkan ke Admin adalah A1B2-C3D4-E5F6-7890. Tanggal kadaluarsa menunjukkan bahwa kode ini berlaku selama 30 hari sejak tanggal penerbitan. Setelah melewati tanggal tersebut, Admin harus meminta kode baru.
Peringatan: Satu Kode per Perangkat
Setiap kode aktivasi hanya berlaku untuk satu perangkat dengan Machine ID yang spesifik. Jika Admin berganti komputer atau mengganti komponen hardware utama (CPU, kartu jaringan), Machine ID akan berubah dan kode lama tidak akan berfungsi. Pengembang harus menghasilkan kode baru berdasarkan Machine ID yang baru.
Tips: Catat Tanggal Kadaluarsa
Pengembang disarankan untuk mencatat setiap kode aktivasi yang diterbitkan beserta Machine ID dan tanggal kadaluarsanya. Dengan demikian, pengembang dapat proaktif mengingatkan Admin sebelum lisensi habis, terutama jika ada jadwal acara wisuda yang mendekat.
Bab 04
Alur Kerja Admin
Admin adalah pengguna utama yang menjalankan aplikasi SAATIRIL di laptop/PC. Seluruh proses dimulai dari Admin: mulai dari aktivasi lisensi, pembuatan proyek, pengaturan session password, hingga monitoring dan penyimpanan foto. Berikut adalah langkah-langkah lengkap yang harus dilakukan Admin secara berurutan.
Langkah 1: Buka Aplikasi SAATIRIL
Jalankan aplikasi SAATIRIL di laptop utama. Jika lisensi belum aktif atau sudah kadaluarsa, layar LicenseGate akan muncul secara otomatis. Layar ini menampilkan banner merah "Aplikasi Terkunci" yang menandakan bahwa Anda harus memasukkan kode aktivasi sebelum dapat menggunakan aplikasi.
Langkah 2: Salin Machine ID dan Kirim ke Pengembang
Di layar LicenseGate, Anda akan melihat Machine ID yang terdiri dari 64 karakter heksadesimal. Klik tombol "Salin" di samping Machine ID untuk menyalinnya ke clipboard. Kemudian kirimkan Machine ID tersebut kepada pengembang melalui WhatsApp, Telegram, atau media komunikasi lainnya. Pastikan 64 karakter lengkap terkirim tanpa terpotong.
Info: Machine ID Unik per Perangkat
Machine ID dihitung dari kombinasi CPU, MAC address, dan hostname perangkat Anda. Jika Anda menggunakan komputer yang berbeda, Machine ID akan berbeda pula dan kode aktivasi lama tidak akan berlaku. Selalu salin Machine ID dari komputer yang akan digunakan saat acara.
Langkah 3: Masukkan Kode Aktivasi
Setelah menerima kode aktivasi dari pengembang, masukkan kode tersebut di field yang tersedia pada layar LicenseGate. Kode aktivasi memiliki format XXXX-XXXX-XXXX-XXXX (16 karakter dengan pemisah tanda hubung). Ketik kode dengan teliti, pastikan huruf besar/kecil sesuai karena kode bersifat case-sensitive. Setelah memasukkan kode, klik tombol "Aktivasi" untuk memvalidasi.
Peringatan: Format Kode Aktivasi
Kode aktivasi harus dimasukkan persis dalam format XXXX-XXXX-XXXX-XXXX. Jika salah satu karakter salah atau terlewat, validasi akan gagal dan muncul pesan "Kode aktivasi tidak valid". Periksa kembali kode yang diterima dari pengembang sebelum memasukkannya.
Langkah 4: Buat Proyek Baru
Setelah lisensi berhasil diaktivasi, aplikasi akan terbuka dan Anda dapat mulai menggunakan fitur-fiturnya. Langkah pertama setelah masuk adalah membuat proyek wisuda baru. Klik tombol "Buat Proyek Baru" dan isi informasi yang diperlukan seperti nama acara, tanggal, dan lokasi penyimpanan foto. Setelah proyek dibuat, sistem akan secara otomatis memulai server LAN.
Langkah 5: Atur Session Password
Sebelum MC dan Operator dapat bergabung ke sesi, Anda harus mengatur session password. Buka pengaturan session password di aplikasi dan masukkan password yang diinginkan. Password ini akan di-hash menggunakan SHA-256 sebelum disimpan, sehingga tidak tersimpan dalam bentuk plain text. Sampaikan password ini kepada MC dan Operator melalui jalur komunikasi yang aman.
Tips: Password yang Mudah Dikomunikasikan
Gunakan password yang mudah disampaikan secara lisan, misalnya "wisuda2026" atau "uantasari26". Hindari karakter spesial yang membingungkan saat diucapkan. Password bersifat case-sensitive, jadi pastikan MC dan Operator mengetahui huruf besar/kecil yang tepat.
Langkah 6: Bagikan LAN URL
Setelah session password diatur, berikan informasi berikut kepada MC dan Operator agar mereka dapat bergabung ke sesi:
URL LAN untuk MC dan Operator
MC Channel 1: http://<admin-ip>:3000/?role=mc&channel=1

MC Channel 2: http://<admin-ip>:3000/?role=mc&channel=2

Operator: http://<admin-ip>:3000/?role=operator

Ganti <admin-ip> dengan IP Address laptop Admin di jaringan lokal (contoh: 192.168.1.100).
Peringatan: Lisensi Kadaluarsa 30 Hari
Setiap kode aktivasi hanya berlaku selama 30 hari sejak tanggal penerbitan. Jika masa berlaku lisensi tinggal 7 hari atau kurang, aplikasi akan menampilkan peringatan berwarna kuning. Segera hubungi pengembang untuk mendapatkan kode baru sebelum lisensi benar-benar kadaluarsa dan aplikasi terkunci.
Bab 05
Alur Kerja MC
Master of Ceremony (MC) mengakses SAATIRIL melalui browser di perangkat yang terhubung ke jaringan LAN yang sama dengan laptop Admin. MC tidak perlu menginstal aplikasi apapun; cukup menggunakan browser modern seperti Google Chrome atau Microsoft Edge. Berikut adalah langkah-langkah lengkap yang harus dilakukan MC untuk bergabung dan mengoperasikan panel MC.
Langkah 1: Buka Browser dan Akses URL Panel MC
Buka browser di perangkat Anda (laptop, tablet, atau perangkat lain yang terhubung ke jaringan yang sama dengan Admin). Ketik URL berikut di address bar browser sesuai dengan channel yang ditugaskan kepada Anda:
URL Panel MC
Channel 1: http://<admin-ip>:3000/?role=mc&channel=1

Channel 2: http://<admin-ip>:3000/?role=mc&channel=2

Ganti <admin-ip> dengan IP Address laptop Admin yang telah disampaikan sebelumnya. Misalnya, jika IP Admin adalah 192.168.1.100 dan Anda ditugaskan di Channel 1, maka URL-nya adalah: http://192.168.1.100:3000/?role=mc&channel=1
Info: MC Buka di Laptop yang Sama dengan Admin
Jika MC berjalan di laptop yang sama dengan Admin, gunakan URL http://localhost:3000/?role=mc&channel=1. Buka di tab browser terpisah dari aplikasi Admin. Pastikan browser dalam mode normal (bukan incognito) agar koneksi Socket.io stabil.
Langkah 2: Masukkan Session Password
Setelah halaman dimuat, Anda akan diminta untuk memasukkan session password. Password ini telah diset oleh Admin dan harus Anda ketahui sebelumnya. Ketik password dengan teliti, ingat bahwa password bersifat case-sensitive (huruf besar dan kecil berpengaruh). Jika password salah, Anda tidak akan dapat bergabung ke sesi dan perlu memasukkan ulang.
Langkah 3: Kontrol Panel MC
Setelah berhasil bergabung, panel MC akan menampilkan antarmuka yang terhubung secara real-time dengan sistem Admin. Anda dapat memanggil nama wisudawan, melihat status foto (sudah diambil atau belum), dan mengatur ritme acara. Setiap aksi yang dilakukan di panel MC akan langsung terlihat di dashboard Admin dan panel Operator tanpa delay yang signifikan.
Panel MC juga menampilkan indikator koneksi ke server sehingga Anda dapat memantau apakah koneksi LAN masih aktif. Jika koneksi terputus, sistem akan secara otomatis mencoba menyambung kembali. Namun jika koneksi tidak pulih dalam waktu lama, segera koordinasi dengan Admin untuk memeriksa jaringan.
Tips: Siapkan Daftar Wisudawan
Sebelum acara dimulai, pastikan Anda sudah memiliki daftar wisudawan yang akan dipanggil sesuai urutan. Hal ini akan mempercepat proses pemanggilan dan mengurangi jeda antar wisudawan. Koordinasikan dengan Admin mengenai channel yang digunakan jika ada dua jalur wisuda yang berjalan paralel.
Bab 06
Alur Kerja Operator
Operator Kamera mengakses SAATIRIL melalui browser di perangkat yang terhubung ke kamera dan jaringan LAN. Sama seperti MC, Operator tidak perlu menginstal aplikasi khusus; cukup menggunakan browser modern. Namun, perangkat Operator harus memiliki kamera yang terhubung dan diizinkan untuk diakses oleh browser. Berikut adalah langkah-langkah lengkap untuk Operator.
Langkah 1: Buka Browser dan Akses URL Panel Operator
Buka browser di laptop/perangkat yang terhubung ke kamera. Ketik URL berikut di address bar:
URL Panel Operator
http://<admin-ip>:3000/?role=operator

Ganti <admin-ip> dengan IP Address laptop Admin. Misalnya: http://192.168.1.100:3000/?role=operator
Langkah 2: Izinkan Akses Kamera
Saat pertama kali membuka panel Operator, browser akan meminta izin untuk mengakses kamera. Klik "Allow" atau "Izinkan" untuk memberikan akses. Jika Anda menolak izin ini, kamera tidak akan terdeteksi oleh panel dan Anda tidak dapat mengambil foto. Jika tidak muncul permintaan izin, periksa pengaturan browser dan pastikan akses kamera diizinkan untuk situs tersebut.
Peringatan: Kamera Digunakan Aplikasi Lain
Jika kamera sedang digunakan oleh aplikasi lain (misalnya Zoom, Skype, atau OBS Studio), browser tidak akan dapat mengaksesnya. Tutup terlebih dahulu semua aplikasi yang menggunakan kamera sebelum membuka panel Operator. Jika kamera tetap tidak terdeteksi, restart browser dan coba lagi.
Langkah 3: Masukkan Session Password
Sama seperti MC, Anda akan diminta memasukkan session password setelah halaman dimuat. Ketik password yang telah diberikan oleh Admin. Password bersifat case-sensitive, jadi pastikan huruf besar/kecil sudah benar. Jika password salah, Anda tidak akan dapat bergabung dan perlu memasukkan ulang.
Langkah 4: Kontrol Kamera
Setelah berhasil bergabung dan kamera aktif, panel Operator akan menampilkan preview kamera secara real-time beserta kontrol-kontrol yang tersedia. Anda dapat mengambil foto wisudawan dengan mengklik tombol "Capture", melakukan retake jika hasil foto kurang memuaskan, dan memilih kamera dari dropdown jika ada lebih dari satu kamera yang terhubung.
Foto yang diambil akan otomatis dikirim ke Admin melalui jaringan LAN dan disimpan ke disk oleh aplikasi Admin. Nama file foto mengikuti format NIM_Nama.jpg, dan jika dilakukan retake, versi baru akan diberi suffix (v2, v3, dan seterusnya). Anda tidak perlu khawatir tentang penyimpanan karena seluruh proses dilakukan secara otomatis.
Tips: Posisi Kamera yang Optimal
Pastikan kamera berada pada posisi dan sudut yang optimal sebelum acara dimulai. Gunakan tripod untuk stabilitas. Atur resolusi kamera ke tingkat tertinggi yang didukung oleh browser. Jika menggunakan mode dual, pastikan kedua kamera sudah terdeteksi dan berfungsi dengan baik di panel Operator.
Bab 07
Sistem Lisensi
SAATIRIL menggunakan sistem lisensi bulanan yang dirancang untuk melindungi penggunaan aplikasi dan memastikan setiap instalasi terautentikasi. Sistem ini terikat ke hardware perangkat Admin melalui Machine ID, sehingga setiap kode aktivasi hanya berlaku untuk satu perangkat tertentu. Berikut adalah penjelasan detail mengenai cara kerja sistem lisensi.
Cara Kerja Lisensi
Ketika aplikasi SAATIRIL dibuka di laptop Admin, sistem akan memeriksa apakah ada lisensi yang valid tersimpan di perangkat. Lisensi disimpan secara terenkripsi dalam file license.dat yang terletak di folder %APPDATA%/SAATIRIL/ pada sistem Windows. File ini berisi informasi kode aktivasi, tanggal penerbitan, dan tanggal kadaluarsa yang dienkripsi untuk mencegah manipulasi.
Jika tidak ada lisensi yang valid atau lisensi sudah kadaluarsa, aplikasi akan langsung menampilkan layar LicenseGate dengan banner merah "Aplikasi Terkunci". Tidak ada masa tenggang (grace period) yang diberikan; aplikasi sepenuhnya terkunci sampai kode aktivasi yang valid dimasukkan. Hal ini memastikan bahwa hanya pengguna dengan lisensi aktif yang dapat mengoperasikan aplikasi.
Proses Pembuatan Kode Aktivasi
Kode aktivasi dihasilkan melalui proses kriptografis yang melibatkan Machine ID, waktu penerbitan, dan secret key khusus. Secara teknis, kode aktivasi adalah 16 karakter pertama dari SHA-256(machineId:monthly:expiryHex:SECRET), yang kemudian diformat dalam pola XXXX-XXXX-XXXX-XXXX. Secret key yang digunakan adalah SAATIRIL-2026-HUMAS-UIN-ANTASARI-BANJARMASIN, yang hanya diketahui oleh pengembang.
Proses validasi kode dilakukan secara lokal di perangkat Admin tanpa perlu koneksi internet. Aplikasi akan menghitung ulang hash berdasarkan Machine ID perangkat dan membandingkannya dengan kode yang dimasukkan. Jika cocok dan belum melewati tanggal kadaluarsa, lisensi akan dianggap valid dan aplikasi terbuka.
Masa Berlaku Lisensi
Detail Masa Berlaku
Tipe Lisensi: Bulanan (Monthly) saja. Setiap kode aktivasi berlaku tepat 30 hari sejak tanggal penerbitan.

Peringatan Kadaluarsa: Jika masa berlaku lisensi tinggal 7 hari atau kurang, aplikasi akan menampilkan peringatan berwarna kuning di bagian atas layar. Peringatan ini mengingatkan Admin untuk segera menghubungi pengembang.

Setelah Kadaluarsa: Aplikasi akan terkunci sepenuhnya. Banner merah "Aplikasi Terkunci" akan muncul dan semua fitur tidak dapat diakses sampai kode aktivasi baru dimasukkan.
Perpanjangan Lisensi
Untuk memperpanjang lisensi, Admin harus mengulangi proses yang sama seperti saat aktivasi pertama: salin Machine ID dari layar LicenseGate, kirimkan ke pengembang, terima kode aktivasi baru, dan masukkan ke aplikasi. Kode aktivasi lama tidak dapat diperpanjang; pengembang harus menerbitkan kode baru yang berbeda untuk setiap periode 30 hari.
Peringatan: Jangan Tunggu Habis
Jangan menunggu lisensi benar-benar kadaluarsa untuk meminta kode baru. Jika ada acara wisuda yang dijadwalkan, pastikan lisensi masih aktif setidaknya 7 hari setelah tanggal acara. Perpanjanglah lisensi sebelum peringatan kuning muncul untuk menghindari kendala teknis di hari H.
Machine ID dan Perubahan Hardware
Machine ID dihitung dari sidik jari hardware perangkat yang mencakup CPU identifier, MAC address kartu jaringan, dan hostname komputer. Jika terjadi perubahan pada salah satu komponen ini, Machine ID akan berubah dan lisensi yang tersimpan menjadi tidak valid. Beberapa skenario yang dapat menyebabkan perubahan Machine ID antara lain:
  • ✓ Mengganti komputer atau laptop yang digunakan
  • ✓ Upgrade atau penggantian prosesor (CPU)
  • ✓ Mengganti kartu jaringan (NIC) atau menggunakan adapter USB LAN yang berbeda
  • ✓ Mengubah hostname komputer
Jika Machine ID berubah, Anda harus menghubungi pengembang untuk mendapatkan kode aktivasi baru. Kode lama tidak akan berfungsi pada Machine ID yang baru.

Troubleshooting
Bagian ini membahas masalah-masalah umum yang mungkin ditemui saat menggunakan SAATIRIL beserta langkah-langkah penyelesaiannya. Jika Anda mengalami masalah yang tidak tercakup di bawah ini, hubungi pengembang untuk bantuan lebih lanjut.
Masalah Lisensi
"Aplikasi Terkunci" muncul saat membuka aplikasi
Penyebab: Lisensi belum diaktivasi atau sudah kadaluarsa. Aplikasi langsung terkunci tanpa masa tenggang jika tidak ditemukan lisensi yang valid.

Solusi: Salin Machine ID dari layar LicenseGate (klik tombol "Salin"), kirimkan ke pengembang, dan masukkan kode aktivasi yang diterima. Pastikan kode dimasukkan dalam format XXXX-XXXX-XXXX-XXXX dengan benar.
"Kode aktivasi tidak valid"
Penyebab: Kode aktivasi yang dimasukkan tidak cocok dengan Machine ID perangkat ini. Kemungkinan kode dibuat untuk komputer lain, atau ada kesalahan saat menyalin Machine ID atau kode aktivasi.

Solusi: Salin ulang Machine ID lengkap dari layar aktivasi (pastikan 64 karakter penuh) dan kirimkan ke pengembang. Minta pengembang untuk menghasilkan ulang kode berdasarkan Machine ID yang benar. Juga periksa apakah kode aktivasi diketik dengan benar termasuk huruf besar/kecil.
"Kode sudah kadaluarsa"
Penyebab: Kode aktivasi yang dimasukkan sudah melewati masa berlaku 30 hari. Setiap kode hanya berlaku selama satu bulan dan tidak dapat diperpanjang.

Solusi: Hubungi pengembang untuk mendapatkan kode aktivasi baru. Prosesnya sama dengan aktivasi pertama: kirim Machine ID, terima kode baru, masukkan ke aplikasi. Kode lama tidak bisa digunakan lagi setelah kadaluarsa.
Peringatan kuning "Lisensi segera berakhir" (sisa 7 hari)
Penyebab: Masa berlaku lisensi tinggal 7 hari atau kurang. Peringatan ini muncul sebagai pengingat agar Admin segera memperpanjang lisensi sebelum terkunci.

Solusi: Segera hubungi pengembang dan minta kode aktivasi baru. Jangan tunda hingga lisensi benar-benar habis, terutama jika ada acara wisuda yang dijadwalkan dalam waktu dekat.
Masalah Koneksi LAN
"Gagal menyambung ke sesi" di panel MC/Operator
Penyebab: Perangkat MC/Operator tidak dapat terhubung ke server SAATIRIL yang berjalan di laptop Admin.

Langkah Pengecekan:
1. Pastikan perangkat terhubung ke jaringan LAN/WiFi yang sama dengan Admin
2. Pastikan aplikasi SAATIRIL sudah berjalan di laptop Admin
3. Periksa apakah IP Address yang dimasukkan di URL benar
4. Coba akses http://[IP-ADMIN]:3000 langsung di browser
5. Nonaktifkan firewall Windows sementara untuk testing
6. Pastikan port 3000 dan 3003 tidak diblokir oleh antivirus
7. Pastikan tidak ada aplikasi lain yang menggunakan port tersebut
"Password salah" saat MC/Operator mencoba bergabung
Penyebab: Session password yang dimasukkan tidak cocok dengan yang diset oleh Admin.

Solusi: Verifikasi kembali password dengan Admin. Password bersifat case-sensitive (huruf besar/kecil berpengaruh). Jika lupa password, Admin bisa mengatur ulang session password dari aplikasi SAATIRIL. Setelah direset, sampaikan password baru kepada semua MC dan Operator.
Koneksi sering terputus di tengah acara
Penyebab: Sinyal WiFi lemah, interferensi, atau beban jaringan terlalu tinggi.

Solusi: Gunakan kabel LAN untuk koneksi yang lebih stabil. Jika harus menggunakan WiFi, pastikan perangkat dekat dengan router dan tidak ada hambatan fisik. Kurangi jumlah perangkat yang terhubung ke router jika memungkinkan. Sistem akan otomatis mencoba menyambung kembali saat koneksi pulih.
Masalah Kamera
Kamera tidak terdeteksi di browser Operator
Langkah Pengecekan:
1. Pastikan kamera terhubung dan dikenali oleh Windows (cek Device Manager)
2. Berikan izin akses kamera saat browser meminta (klik "Allow")
3. Jika kamera digunakan aplikasi lain (Zoom, OBS), tutup aplikasi tersebut terlebih dahulu
4. Coba ganti kamera dari dropdown di panel Operator
5. Restart browser dan coba lagi
6. Pastikan menggunakan browser Chrome atau Edge versi terbaru
Foto tidak tersimpan di folder
Penyebab: Hanya Admin (Electron app) yang bisa menyimpan foto ke disk. Operator di browser tidak menyimpan secara langsung; foto dikirim melalui LAN ke Admin untuk disimpan.

Solusi: Pastikan aplikasi SAATIRIL di laptop Admin berjalan dan terhubung ke jaringan. Periksa koneksi antara Operator dan Admin. Jika koneksi terputus saat foto dikirim, foto mungkin hilang dan perlu di-retake setelah koneksi pulih.
Masalah Lainnya
Aplikasi SAATIRIL tidak mau terbuka (Windows)
Langkah Pengecekan:
1. Untuk versi Portable: klik kanan file .exe, pilih "Run as Administrator"
2. Untuk versi Installer: jalankan dari shortcut Desktop atau Start Menu
3. Nonaktifkan antivirus sementara (Windows Defender kadang memblokir aplikasi baru)
4. Pastikan tidak ada instance SAATIRIL lain yang sedang berjalan (cek Task Manager)
5. Coba restart komputer dan jalankan ulang aplikasi
Data sinkronisasi tidak muncul di perangkat lain
Penyebab: Koneksi terputus saat data dikirim, atau perangkat belum terautentikasi dengan session password yang benar.

Solusi: Pastikan semua perangkat sudah memasukkan session password dengan benar. Periksa indikator koneksi di header masing-masing panel. Jika koneksi pulih setelah terputus, data akan otomatis tersinkronisasi melalui mekanisme SYNC_DB. Jika masih tidak muncul, refresh halaman browser dan masukkan ulang password.
